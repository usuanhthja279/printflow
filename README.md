# PrintFlow / J.D.Printex

Printing workflow application, project plans and supplied UI design references.

The application source and its setup instructions are in [printflow application](<printflow application/README.md>). Read [AGENTS.md](<printflow application/AGENTS.md>) before making application changes.

Use the Gradle wrapper for the Java backend and the documented native Windows services. Current development does not require Docker.

Local environment files, credentials, customer uploads, database contents, dependencies, build output and generated review bundles are excluded from version control. Configure these privately using the checked-in environment examples and application setup instructions.
